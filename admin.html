CUSTOMER GUIDE

Panduan Setup Auto Install

Panduan yang dapat dibaca pelanggan sebelum memasang VPS Agent dan menghubungkan server.

1. Siapkan VPS

Gunakan Ubuntu/Debian dengan akses root, Node.js 20+, systemd, domain opsional, dan firewall aktif. Domain digunakan sebagai Host member; IP tetap digunakan internal untuk mesin.

2. Jalankan installer VPS Agent
git clone https://github.com/usnulnifah-web/ssh-store-vps-agent-installer.git
cd ssh-store-vps-agent-installer
sudo bash install.sh

Installer meminta secret HMAC, bind address, port agent, dan IP backend yang boleh mengakses agent.

3. Atur koneksi di Admin → Server & Protocol

Isi IP VPS, port SSH, username SSH, pilih Password atau SSH Key, lalu isi domain publik bila tersedia. Jangan menaruh credential di frontend atau repository publik.

4. Atur Admin → Konfigurasi Protocol

Atur domain, WebSocket path, SSL/TLS port default 443, OpenVPN WebSocket, format file, lalu simpan. Jika provider memakai port berbeda, admin dapat mengganti angka 443 secara manual.

5. Uji sebelum menjual

Uji health agent, buat satu akun percobaan, cek login SSH, WebSocket, OpenVPN, masa aktif, notifikasi, file TXT, dan file OVPN. Jangan aktifkan produk sebelum pengujian berhasil.

6. Troubleshooting

Gunakan systemctl status ssh-store-agent, journalctl -u ssh-store-agent -f, cek firewall, DNS, port SSL, path WebSocket, dan kesamaan secret HMAC antara website dan agent.
